Three weeks later

  • Learn triggers, not tables. Pick one trigger word a week, like "mo" (séimhiú) or "ár" (urú), and drill only that.
  • Say it in phrases. Mutations live in the ear, so repeat "mo bhád, ár mbád" aloud until the wrong form sounds odd.
  • Log each pattern once it sticks. A running count shows which triggers you own and which still trip you up.
